Midnight Vault — a top-down 2D stealth heist game. Slip past 3 patrolling guards (Marco, Rosa, Dante) and 2 sweeping wall cameras, steal the Star Sapphire, Vault Cash and Golden Mask, then slip out the EXIT before the alarm hits 100. Vision cones, line-of-sight cover, an alarm meter that rises while you're spotted and decays while you're hidden, and 2 smoke bombs that buy you a few seconds of invisibility. Plain canvas, no engine, no network — every line written fresh for this bounty.

## Run it

```sh
cd game && python3 -m http.server 8000
```

Then open http://localhost:8000 — move with WASD / arrow keys, E for a smoke bomb, P to pause, R to retry.
